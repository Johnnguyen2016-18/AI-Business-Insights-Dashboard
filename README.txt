AI Business Insights Dashboard — Project 3
===========================================

WHAT THIS IS
A local-first portfolio demo for ACME Business Solutions using fictional IT support request data. It shows request volume, category and priority distribution, rule-based observations, suggested next steps, and a copyable business-owner summary. The 30/90-day controls use numbered sample days, not real calendar dates.

FILES
- index.html: interactive dashboard.
- README.txt: these instructions.

HOW TO TEST LOCALLY
1. Extract this ZIP to a folder.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
4. Change the reporting window between 30 and 90 days.
5. Filter by request category and verify the KPI cards, charts, observations, table, and summary update. The window labels say “sample days” because the sample records use day numbers rather than real dates.
6. Click Copy summary to test copying. If your browser blocks clipboard access for local files, select and copy the summary manually.

LIMITATIONS
- All records are fictional sample data.
- Insights are rule-based examples, not generated by a live AI model.
- There is no backend, live ticketing connection, or production data.
- No tickets are changed, approvals issued, or external actions taken.
- Review recommendations against real policy and records before making decisions.

GITHUB PAGES
This is a static HTML demo and can be hosted on GitHub Pages. Upload index.html to the root of a repository configured for GitHub Pages. Never upload real user records, passwords, MFA codes, confidential data, or production credentials.
